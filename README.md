# AYYAPPA - Premium Car Accessories

Interactive, high-performance scroll-driven car animation landing page for **AYYAPPA Car Accessories**.

## Features
- **Canvas-based 60fps frame rendering** tied to scroll position
- **Preloading mechanism** for instant visual feedback
- **Responsive design** with modern typography and overlay styling
- **Optimized caching** headers for Netlify deployment

## Deployment
Configured for automatic continuous deployment with Netlify via GitHub.
